# Chiang Mai Ecosystem Mapping

Interactive map of Chiang Mai’s child welfare ecosystem — insights view and full catalog explore.

**Live site:** https://ethanollamah.github.io/ChiangMai-Ecosystem-Mapping/

## Local preview

```bash
python3 -m http.server 8765 --directory preview
```

Then open http://localhost:8765

## Repository layout

- `preview/` — static site (GitHub Pages source)
- `scripts/` — data build and import scripts
- `raw/` / `outputs/` — source tables and analysis outputs
